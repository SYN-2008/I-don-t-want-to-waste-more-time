# 小眼 · 页面助手

**主用法只有一句话：在网页上划选题目 → 按 `Alt+S` → 答案直接流式浮在页面上，结束时自动复制到剪贴板。**

不截屏、不开侧边栏、不切标签页、不用来回粘贴。侧边栏退居二线，只当档案柜用（提取过什么、问过什么都在里面）。

## 三种用法

| 操作 | 用途 | 花钱吗 |
|---|---|---|
| 划选文字 → `Alt+S`，或点文字旁边的「⚡ 问小眼」 | **日常就用这个**：答案浮在页面上，可拖动、可复制 | 要 API Key |
| `Alt+A`（点选模式） | 页面禁止选中/复制（智慧树这类）时用：鼠标指哪高亮哪，**点一下**哪块就问哪块，`Esc`/右键退出 | 要 API Key |
| 侧边栏「提取题目」→ 复制题目 / 填到 DeepSeek | 不想配 Key 时的人工路线 | 不花 |

答案卡片可以拖动到不挡题目的位置，按 `Esc` 关掉，`复制答案` 一键拿走。

## 之前的路线（仍然保留）

```
网页 → 只挑题目 → ① 存成桌面 Word 文档
                 ├─ ② 点「复制题目」→ 自己粘到 DeepSeek
                 ├─ ③ 点「填到 DeepSeek」→ 自动填进输入框，你按回车
                 └─ ④ 点「让它直接答」→ 侧边栏直接出答案（需 API Key）
```

## 它怎么"只认题目"

在页面里跑一套规则：

1. **先去噪**：把 `header / nav / footer / aside / 广告 / 评论 / 推荐 / 侧栏 / 分页 / 弹窗 / 目录（toc、catalog、menu、treeview、outline…）` 等块整片丢掉。
2. **再选容器**：在 `main / article / .content / .exam / .question / .paper …` 这些候选里打分，得分由「题目信号」决定（A/B/C/D 选项、下列/正确的是/填空/简述/（）/？），分数高的那层留下，避免只抓到第一道题、也避免抓到左侧目录树。
3. **按题号切段**：识别 `1.` `1．` `1、` `（1）` `第1题` `一、` 这些开头，每段连同后面的选项行一起保留。
4. **过滤目录行**：带省略号/长点线/页码结尾的行（`第一章 绪论 ………… 1`）直接丢掉；`一、单项选择题` 这类大题标题也丢掉，不算成一道题。
5. **严格模式**：一段里必须出现 A/B/C/D 选项，或"下列/正确的是/填空/简述/（）/____/？"这类作答信号，才判定成题目。都不满足时先试宽松模式（但会排除像目录条目的短标题）；再不行才退化成"整页正文"。
6. **兜底**：识别不到题目时（比如纯文章页），自动退化成去噪后的整页正文，并在侧边栏提示你改用划选。

**题目在内嵌 iframe 里的网站（不少题库站是这样）**：扩展会同时读取页面里所有框架，挑"真正有题目"的那一帧，而不是只在最外层读（最外层往往只剩导航和目录 —— 这是之前抓到目录内容的原因）。

**最准的用法**：先在网页上把题目划选出来，再点按钮 —— 有选区时只认选中的文字，规则完全不参与。设置里可以关掉这个行为。

## Word 文档

- 文件名形如 `题目提取_2026-10-12.docx`，放在你选的文件夹里。
- 默认「同一天累积到一个文档」：当天提取的每一批都会追加进同一个文件（重新生成整份，内容累积）。
- 也可以改成「每次提取新建一个文档」。
- 文档是标准 `.docx`，Word / WPS / Pages 都能直接打开，中文用等线。
- 侧边栏答案是顺便写进去的，题目后面会带一段"答案"。

## 安装

1. 把 `screen-pet` 文件夹放到一个固定位置。
2. Chrome 地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）。
3. 打开右上角 **开发者模式**。
4. 点 **加载已解压的扩展程序**，选中 `screen-pet` 文件夹（里面有 `manifest.json` 的那层）。
5. 装完会自动弹出设置页 → 点「选择文件夹」→ 弹窗会直接定位到桌面，新建一个 `题目提取` 文件夹选上。
6. 点浏览器右上角的小眼图标，侧边栏就打开了。

## 发给别人

把整个 `screen-pet` 文件夹压成 zip 发过去，对方解压后按上面步骤加载即可。

- 想更正式：**Edge 加载项商店开发者账号免费**，可以直接提交；Chrome 应用商店需要一次性 5 美元注册费。
- 上架后对方不用开开发者模式，但要过隐私审核（这个扩展要读所有网页内容，审核会问）。

## 设置项速查

| 项目 | 默认 | 说明 |
|---|---|---|
| 划选后显示「问小眼」小按钮 | 开 | 关掉就只能用快捷键 |
| 划选后立刻自动提问 | 关 | 打开后选中即发，会持续消耗额度 |
| 答案出来自动复制到剪贴板 | 开 | 方便直接粘贴 |
| 默认提取方式 | 智能识别题目 | 可切「整页正文」 |
| 优先用划选文字 | 开 | 有选区就只认选区，最准 |
| 单次最多提取多少字 | 20000 | 防止页面太长 |
| 文档名 | 题目提取 | 决定文件名前缀 |
| 写入方式 | 同一天累积一个文档 | 或每次新建 |
| 每次提取后自动写入 Word | 开 | 关掉就只在点「存到 Word」时写 |
| 默认开启跟随 | 关 | 打开后页面一变自动提取 |
| 跟随触发延迟 / 最短间隔 | 1500 / 15000 毫秒 | 控制自动提取的节奏 |

设置页**改完即存**，不用找保存按钮。`Alt+S` / `Alt+A` 如果和别的软件冲突，去 `chrome://extensions/shortcuts`（Edge 是 `edge://extensions/shortcuts`）改。

## 花多少钱

DeepSeek 按 token 计费，官网价（人民币，2026-08-17 起生效）分**高峰 / 空闲**两档：

| 模型 | 时段 | 输入（每百万 token） | 输出（每百万 token） |
|---|---|---|---|
| `deepseek-flash` | 空闲 | 1.5 元 | 4.5 元 |
| `deepseek-flash` | 高峰 | 3 元 | 9 元 |
| `deepseek-v4-pro` | 空闲 | 4.5 元 | 13.5 元 |
| `deepseek-v4-pro` | 高峰 | 9 元 | 27 元 |

高峰时段是**北京时间 9:00–12:00、14:00–18:00**（工作日），其余时间（含晚上和周末）都是空闲价，便宜一半。

粗算（用 `deepseek-flash`）：

- **划选问一道题**（选 100~200 字，答案几百字）：空闲约 **0.002 元/次** → **10 元 ≈ 5000 次**
- 同一件事放到高峰时段：约 0.0035 元/次 → 10 元 ≈ 2800 次
- **整页抓取来问**（上限 2 万字）：空闲约 **0.03 元/次** → 10 元 ≈ 300 次

所以只要用「划选即答」，10 块钱够用很久（一天 50 次的话，能撑两三个月）；**费钱的是「整页正文」模式**，差十倍以上。

> 「思考模式」**默认是关的**（0.3.4 起）。它在 DeepSeek V4.1 上是默认开的，思考内容同样按输出计费，开着会让成本明显上去、回答也慢。遇到确实要推理的难题再去设置页打开。

## 边界与注意

- 浏览器内置页（`chrome://`）、扩展商店页、PDF 阅读器读不了，这是浏览器的硬限制。
- 「读取和更改您在所有网站上的数据」这条权限警告绕不开。
- 用 API 出答案时，提取到的文字会发给 DeepSeek。有隐私内容的页面自己掂量。
- 有些题库站把选项写在图片里，或者用 canvas 画题目 —— 那种纯文字提取拿不到（旧版截图方案能拿到，但按你的要求已经彻底去掉了）。
- 跟随模式开着又开了自动写 Word，一个下午能攒出很长的文档，注意别让它跑太久。

## 已知可改进处

- 题目识别是启发式规则，特殊排版的题库可能需要手动划选。
- 「填到 DeepSeek」依赖对方页面的输入框结构，对方改版可能要跟着调 `deepseek.js` 里的选择器。

## 更新记录

### 0.4.2

- **修了一个藏在很深处的 bug：`Alt+A` 从装上第一天起就没生效过** —— manifest 里注册的命令叫 `ask-whole-page`，后台监听的却是 `ask-page`，两个名字对不上，按了等于没按。
- **新增「点选模式」（就是修好的 Alt+A）**：智慧树这类站点禁止选中、禁止复制，"划选"这条路根本走不通。点选模式不依赖选中：按 `Alt+A` 进入后，鼠标指到哪块就绿框高亮哪块，**点一下**直接把那块文字抓来问；从点到面自动找边界（爬到"整页那么大"就停，不会把整卷都拖进来），`Esc` 或右键退出。
- 内容脚本现在也注入 `about:blank` 之类的空白框架（`match_about_blank`），部分站点把题目塞在这种框架里。
- 智慧树适配现状：点选模式 + 字体还原（cmap 门卫是通用的）都已就位。如果智慧树把题目画在图片/canvas 里，那是纯文字方案的边界，需要时再议 OCR。

### 0.4.1

- **修「没有生僻字也识别不了」**：0.4.0 的字体还原太激进 —— 只要页面上存在那份 `font-cxsecret` 字体，它就对**每一个**汉字做字形比对，于是把本来正常的题目改成了别的字，DeepSeek 拿着改坏的文字答出一堆风马牛不相及的题。现在**先把字体文件里的字符表解析出来，只有字体真正定义过的码位才可能是加密字**；表里没有的字一个字都不动。
- **比对方式也换了**：改成"裁掉空白 → 缩放到统一尺寸 → 位运算求交并比"，同一个字不管字号、位置、还是换了字体的设计风格都能对上；匹配要求"最像的足够像、且明显比第二像的更像"，达不到就保留原字。
- **只在确有把握时才还原**：整体还原率或平均相似度不达标时，直接用**页面原文**发问，并明确告诉你"没还原、答案可能不准"，而不是拿还原坏的文字去答。
- **新增「原文重问」按钮**：一键跳过字体还原，把页面原文直接发给 DeepSeek，方便对照。
- **快捷键 Alt+S 也走同一条路**：以前 Alt+S 完全不经过字体还原（只有点小气泡才还原），学习通上按快捷键必然拿到乱码；现在两条路都交给拿到选区的那个框架处理。
- **回答改成"直接给答案"**：系统提示词换成"一行一题：第1题：B"，不分析、不复述题干。旧默认提示词会自动升级，自己改过提示词的不会被覆盖。

### 0.4.0

- **自动还原学习通加密字体（划选路径）**：学习通用自定义字体（`font-cxsecret`）把部分汉字换成假字符 —— 屏幕上显示正常，但选中/复制出来的文字本身就是乱码，DeepSeek 因此说「乱码严重」。现在划选时插件会自动检测页面里的加密字体，取出来在**本地**做字形比对（密文字形 vs 6000 常用字真字形），把乱码还原成真字后再发给 DeepSeek。不发请求、不花钱。卡片上会显示还原了多少字；个别没还原的字会保留原样并提示。
- 说明：这是纯前端的字形比对方案，属于实验性质 —— 常用字基本能对上，生僻字可能保留乱码。若还原率不理想，备选方案是截图 OCR（当初按需求去掉了）。

### 0.3.4

- **默认关闭「思考模式」**：DeepSeek V4.1 默认先思考再回答，而思考内容也按输出计费、且可能在 `max_tokens` 用尽时把正文挤成空（表现为「没答出来」）。答题场景改为默认关闭，设置页可随时打开。
- **报错可诊断**：空回答不再只说「没有返回内容」，而是给出真实原因（思考占了额度 / 被 max_tokens 截断 / 内容被安全策略拦下）并附 `finish_reason` 和 `usage`；接口报错保留 HTTP 状态与原始返回；流式过程中收到的 error 事件也会被抛出而不是被吞掉。
- 浮层卡片新增「**复制诊断**」按钮：一键复制错误、原始返回、字数、地址，直接发给开发者定位。
- 最近一次报错会存进本地，侧边栏「诊断」也能看到。

### 0.3.3

- **修复「答案卡片被网站改写」**：有站点的防作弊脚本会定位页面上新增的浮层，往里面写自己的警告文字（比如「内容与页面内容不符」）。浮层改为 **closed Shadow DOM** 并去掉可定位的 id，页面脚本再也摸不到卡片内部。
- **复制链路防劫持**：新增 `clipboardWrite` 权限，自动复制答案优先走异步剪贴板 API（不触发 copy 事件，页面的防复制钩子拦不到）；execCommand 回退路径也在捕获阶段写入自己的数据并拦截事件，防止复制到剪贴板的答案被网站替换成它的警告。

### 0.3.2

- **修复模型名**：DeepSeek 已把 `deepseek-chat` / `deepseek-reasoner` 下线，现在必须用 `deepseek-flash`（或 `deepseek-v4-pro`）。旧配置会在读取时**自动迁移**并回写，不用手动改。
- 设置页的模型输入框加了候选与提示。

### 0.3.1

- 错误提示中文化：402（余额不足）、401（Key 无效）、429（限流）等状态码直接给出人话和下一步该做什么。

### 0.3.0

- **新增「划选即答」**：在网页上划选文字，旁边冒出一个小按钮，点一下答案就**流式浮在页面上**（可拖动、可复制、自动进剪贴板）。不需要打开侧边栏。
- **新增全局快捷键**：`Alt+S` 问选中的文字，`Alt+A` 抓整页题目来问。整个流程压到「划选 + 按一下」。
- **答案由后台流式推送**（SSE），字一句句打出来，不用干等十几秒。
- `content.js` 现在注入所有框架（含 iframe），所以学习通那种「题目在内嵌页」的情况也能划选即答。
- 侧边栏变成档案柜：用快捷键问出来的答案也会自动进历史，可以回头复制。

### 0.2.2

- 新增**诊断**按钮（侧边栏底部）：点一下会检查当前页面的所有框架，列出每个框架的地址、文字长度、识别到几道题、判定模式、开头文字，并判断正文是否被自定义字体加密。识别不准时，点它 → 复制诊断信息 → 发给开发者即可定位。
- 针对**学习通 / 超星**这类结构补充了识别区域（`.questionLi` `.TiMu` `.mark_item` `.qtContent` `#exam-ans` 等），并把答题卡、题目导航、章节树整块排除。

### 0.2.1

- 修复「抓到的全是目录内容」：现在会扫描页面里**所有框架（iframe）**，按"是否真的识别到题目"挑最合适的那一帧，而不是只读最外层。
- 大幅加强对目录/导航的过滤：新增 `toc / catalog / menu / treeview / outline / left-menu / sidebar` 等整块剔除，以及带省略号页码的目录行、`一、单项选择题` 这类大题标题的行级过滤。
- 新增严格/宽松两级判定：先要求有选项或作答信号；都不满足才放宽，并排除"短标题型"条目，避免把目录条目当成题目。
- 侧边栏卡片会标注内容来自「内嵌页」，识别失败时会提示改用划选。

## 识别不准时怎么办

1. 先在侧边栏底部点「**诊断**」，再点「**复制诊断信息**」。
2. 报告里会写清：有几个框架、每个框架读到多少字、识别到几道题、开头文字长什么样。
3. 几个常见结论：
   - 某个框架「识别到题目 0 道」但开头文字确实是题目 → 题号格式特殊，需要按报告里的实际格式调整规则。
   - 报告里出现「**字符加密迹象偏高**」→ 页面正文用自定义字体渲染，DOM 里本来就是乱码，纯文字方案拿不到，只能改用别的办法。
   - 所有框架文字长度都是 0 → 内容是 canvas / 图片渲染，或者页面还没加载完。
