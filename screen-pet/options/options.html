小眼 · 设置

这些设置只保存在你这台电脑的浏览器里，不会上传。

划选即答（推荐日常就用这个）

在网页上把题目划选出来 → 旁边冒出一个小按钮 → 点一下，答案直接流式浮在网页上。 也可以完全不用鼠标：划选后按 Alt+S；按 Alt+A 是「不管选没选，都抓整页题目来问」。

题目提取

Word 文档存到哪

选一个文件夹（弹窗会直接定位到桌面），提取出来的题目会自动写成 .docx。

当前：未选择

没选文件夹时，文档会落到浏览器下载目录下的同名子文件夹。

送进 DeepSeek

两条路都留着：① 在侧边栏点「复制题目」，自己去 DeepSeek 网页粘贴 —— 不需要 API Key； ② 点「填到 DeepSeek」，自动打开/切到 chat.deepseek.com 并把题目填进输入框 —— 你只按一下回车； ③ 点「让它直接答」，用下面的 API Key 直接在侧边栏出答案，不用切页面。

跟随模式

打开后，页面内容稳定下来时会自动提取一次题目。如果开了自动写 Word，就会持续累积到当天的文档里。
